# 🩺 Diabetes Risk Prediction using Machine Learning

A healthcare-focused Machine Learning project that predicts diabetes risk using medical and lifestyle attributes.

This project demonstrates how ML can assist in early risk detection and health awareness.

---

# 📌 Project Overview

Diabetes is a chronic medical condition affecting millions worldwide. Early detection and preventive measures can significantly reduce complications.

This project applies Machine Learning techniques to analyze medical data and predict whether a person is at risk of diabetes.

The goal is not diagnosis, but risk awareness and data-driven insights.

---

# 🎯 Objectives

- Analyze medical and health-related data  
- Perform data preprocessing and visualization  
- Train a predictive ML model  
- Evaluate model performance  
- Identify key diabetes risk factors  
- Promote awareness using data insights

---

# 📊 Dataset Information

This project uses the **PIMA Indians Diabetes Dataset**, a well-known dataset in healthcare ML research.

### Features include:

- Pregnancies  
- Glucose Level  
- Blood Pressure  
- Skin Thickness  
- Insulin Level  
- BMI (Body Mass Index)  
- Diabetes Pedigree Function  
- Age  

### Target Variable:

- Outcome (0 = No Diabetes, 1 = Diabetes Risk)

---

# ⚙️ Machine Learning Workflow

### 1️⃣ Data Cleaning
- Identified invalid zero values  
- Replaced them using mean imputation  

### 2️⃣ Exploratory Data Analysis
- Statistical summaries  
- Correlation heatmap  
- Feature distribution analysis  

### 3️⃣ Feature Selection
- Selected relevant health attributes  

### 4️⃣ Model Training
- Random Forest Classifier used  

### 5️⃣ Model Evaluation
- Accuracy Score  
- Confusion Matrix  
- Feature Importance

---

# 🤖 Model Choice

### Random Forest Classifier

Chosen because:
- Handles non-linear data well  
- Robust to noise  
- Provides feature importance  
- Performs well on medical datasets
