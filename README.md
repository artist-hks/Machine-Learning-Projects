# 🎮 Game Addiction Risk Detector

A Machine Learning project that analyzes gaming behavior and mental health indicators to detect potential addiction risk.

This project explores how gaming habits relate to psychological well-being using real survey-based data.

---

## 📌 Project Overview

Online gaming is widely popular among students and young adults. While gaming can be entertaining and social, excessive gaming may be linked to anxiety, reduced life satisfaction, and behavioral changes.

This project applies Machine Learning to:

- Analyze gaming behavior patterns  
- Study mental health-related scores  
- Detect potential addiction risk levels  
- Provide simple lifestyle recommendations  

---

## 🎯 Objectives

- Understand relationships between gaming and mental health  
- Perform data analysis and visualization  
- Build classification models  
- Identify important risk factors  
- Generate actionable insights  

---

## 📊 Dataset

The dataset is based on survey responses related to:

- Gaming habits  
- Mental health indicators  
- Lifestyle patterns  

It includes multiple psychological scoring criteria such as:

- Anxiety-related scores  
- Life satisfaction measures  
- Social behavior indicators  

*(Dataset used for educational and research purposes.)*

---

## ⚙️ Machine Learning Workflow

1. Data Cleaning  
2. Handling Missing Values  
3. Feature Selection  
4. Risk Score Creation  
5. Model Training (Decision Tree)  
6. Model Evaluation  
7. Visualization & Insights  

---

## 🤖 Model Used

### Decision Tree Classifier

Chosen because:
- Easy to interpret  
- Works well on survey data  
- Provides feature importance  

---

## 📈 Visualizations

The project includes:

- Score distributions  
- Risk level comparisons  
- Feature importance charts  
- Confusion matrix  

These help understand behavioral patterns clearly.

## 💡 Key Insights

- Certain mental health indicators correlate with gaming intensity  
- Behavioral patterns can signal potential risk  
- ML can help in early detection of unhealthy habits
